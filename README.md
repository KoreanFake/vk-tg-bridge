# VK → Telegram Bridge

**Self-hosted мост между сообществом ВКонтакте и Telegram.** Сообщения клиентов вашего сообщества VK приходят в закрытую Telegram-группу (отдельная тема на каждого клиента), а ответы сотрудников из Telegram уходят клиентам во ВКонтакте от имени сообщества.

Не нужны платные платформы автоматизации и включённый домашний компьютер: один контейнер на любом VPS (~256 МБ RAM), только исходящие соединения — публичный IP, домен и открытые порты не требуются.

## Возможности

- 📥 Приём сообщений VK (Bots Long Poll API 5.199): текст, фото, документы, голосовые; видео — ссылкой.
- 🗂 Отдельная тема Telegram на каждого клиента; повторные обращения — в ту же тему; темы не дублируются при перезапуске.
- 📤 Ответы из Telegram → VK: текст, фото с подписями, документы, голосовые.
- 🟣 Отражение в Telegram ответов, отправленных прямо из интерфейса ВК.
- 🏷 Статусы диалога: 🆕 Новый · 🔄 В работе · ✅ Отвечено · 📁 Закрыто.
- ⏰ Напоминания о необработанных обращениях (интервалы и рабочие часы настраиваются).
- 🔁 Очередь исходящих с повторами, идемпотентность (нет дублей), обработка «клиент запретил сообщения».
- 🔒 Белый список сотрудников, админ-команды `/status /stats /health`, удаление данных клиента `/forget`.
- 💾 SQLite (WAL), резервное копирование со сроком хранения, логи без секретов и полных текстов.

## Быстрый старт (15–20 минут)

1. **[Создайте Telegram-бота и группу](docs/setup-telegram.md)** — получите токен бота, ID группы, ID сотрудников.
2. **[Подключите сообщество ВКонтакте](docs/setup-vk.md)** — получите токен сообщества и ID, включите Long Poll.
3. **[Разверните на VPS](docs/deploy-vps.md)** — одна команда-установщик:

```bash
git clone https://github.com/KoreanFake/vk-tg-bridge.git && cd vk-tg-bridge
bash scripts/setup.sh   # спросит токены и ID, всё установит и запустит
```

4. Проверка: клиент пишет сообществу в VK → тема появляется в Telegram; ответ в теме → доходит клиенту в VK.

## Требования

- Linux VPS: 1 CPU, 512 МБ RAM, 1 ГБ диска (проверено на Ubuntu 22.04/24.04).
- Docker + Docker Compose (установщик поставит сам на Ubuntu/Debian).
