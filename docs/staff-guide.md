# Памятка сотрудника

## Как это работает

Клиент пишет вашему сообществу во ВКонтакте → его сообщение появляется в закрытой Telegram-группе в **отдельной теме** с именем клиента. Вы отвечаете прямо в этой теме — клиент получает ответ во ВКонтакте от имени сообщества. Открывать ВКонтакте не нужно.

## Правила

1. **Отвечайте только в теме клиента.** Можно текст, фото (с подписью), документы, голосовые.
2. Сообщение, начинающееся с «/» или «!», клиенту **не уходит** — используйте для служебных реплик.
3. Следите за статусом темы (эмодзи в названии): 🆕 новый → 🔄 в работе → ✅ отвечено → 📁 закрыто. Переключайте кнопками под закреплённым сообщением.
4. Бот подтверждает доставку: «✅ Ответ доставлен клиенту». Нет подтверждения — клиент ответ не получил.
5. Если клиент написал в закрытый диалог — тема снова станет 🆕.
6. Бот напомнит, если клиент ждёт ответа слишком долго.
7. Если пришло «⛔️ клиент запретил сообщения» — свяжитесь с клиентом другим способом.

## Команды бота

- `/start` — о боте, `/help` — эта инструкция кратко.
- `/status`, `/stats`, `/health` — для администраторов.
