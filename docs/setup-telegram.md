# Создание Telegram-бота и закрытой группы с темами

## Бот

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`, задайте имя (например, «Моя компания · VK Bridge») и username (обязан заканчиваться на `bot`).
2. Скопируйте токен (вида `123456:AAE...`) — это `TG_TOKEN` в `.env`. Никому не передавайте токен; если он утёк — `/revoke` у BotFather.
3. У BotFather: `/setprivacy` → выберите бота → **Disable** (иначе бот не увидит сообщения сотрудников в группе).
4. `/setcommands` не обязателен; команды: `start, help, status, stats, health, forget`.

## Группа

1. Создайте **группу**, включите в настройках группы **«Темы» (Topics)** — группа станет супергруппой-форумом.
2. Сделайте группу **закрытой** (приватной), приглашайте сотрудников по ссылке с ограничениями.
3. Добавьте бота в группу и назначьте **администратором** с правами: «Управление темами», «Закрепление сообщений», «Отправка сообщений».
4. Узнайте ID группы: добавьте в группу @userinfobot (или @getmyid_bot) — он покажет ID вида `-100xxxxxxxxxx` → `TG_GROUP_ID`. Затем служебного бота можно удалить.
5. Узнайте Telegram ID каждого сотрудника (@userinfobot → `/start`) и впишите в `TG_ALLOWED_USER_IDS` через запятую. Администраторы — в `TG_ADMIN_IDS`.

## Если темы недоступны

Бот автоматически переключится в запасной режим: на каждого клиента создаётся якорное сообщение, а ответы отправляются строго через **reply** на сообщения этого диалога — перепутать адресата невозможно.
