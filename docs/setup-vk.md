# Подключение сообщества ВКонтакте

> В новом интерфейсе ВК раздел может называться иначе или прятаться в «Дополнительно». Прямая ссылка всегда работает: `https://vk.ru/public<ID>?act=api` (подставьте числовой ID сообщества).

1. Откройте ваше сообщество → **Управление** → **Работа с API** → **Ключи доступа** → «Создать ключ».
2. Отметьте права: **управление сообществом**, **сообщения сообщества**, **фотографии**, **документы**. Подтвердите создание.
   Скопируйте токен (`vk1.a.…`) — он понадобится для `.env` (`VK_TOKEN`). Токен показывается один раз.
3. Откройте вкладку **Long Poll API**: включите переключатель, версия API — **5.199** (мы также передаём версию явно в каждом запросе).
4. Во вкладке **Типы событий** отметьте: **Входящее сообщение** (обязательно) и **Исходящее сообщение** (чтобы ответы из интерфейса ВК отражались в Telegram). Остальные — по желанию, бот лишние игнорирует.
5. ID сообщества — число на странице «Управление» (или в ссылке «club123456» → `123456`). Запишите в `VK_GROUP_ID` **без минуса**.
6. **Сообщения сообщества** должны быть включены: Управление → Сообщения → «Сообщения сообщества включены».
7. Токен создаёт любой **администратор сообщества**; личный токен пользователя не нужен и не подходит.

## Проверка

После запуска бота отправьте в группе Telegram команду `/health` — должен быть ответ «VK API: доступен ✅».

## Важно

- Отвечать через API можно только пользователям, которые **первыми написали** сообществу (ограничение VK).
- Лимиты VK: 5 000 исходящих сообщений в сутки, до 20 запросов/сек, текст до 4096 символов, до 10 вложений. Бот обрабатывает превышения повторами, но при массовой рассылке VK может заблокировать отправку — этот бот рассылок не делает.
- Если VK выпустит новую версию API, обновите `VK_API_VERSION` в `.env` и перезапустите. Версии Long Poll ниже 5.81 отключены с 01.12.2024.
